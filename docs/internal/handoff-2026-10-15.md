## Decisions for Dan

1. **#144 in 0.2.2:** web links don't open on Windows in the released 0.2.2
   ("No service matching 'OpenURL'"). #147 is on main now: a 0.2.2.1, or
   ship it in 0.2.3.
2. **#148 now or in 0.2.4** (above).
3. **The About window on GNUstep (#122):** the "Info" title, the faint
   GNUstep logo behind the Author and Copyright lines (an NSImageView of
   `LogoGNUstep` over the whole panel) and Esc not closing it are all
   libs-gui `GSInfoPanel`. Either a libs-gui patch under
   `docs/UPSTREAM_POLICY.md`, or an About window of the app's own from
   standard controls. "About MarkdownViewer" in Help and Check for Updates
   in File on Windows are WinUITheme's menu layout.
4. **CUPS on Linux (#138):** the AppImage has never built GSCUPS (no
   `libcups2-dev` in the image); Print uses GNUstep's own path. #138 writes
   `--disable-cups` out. Adding CUPS is a separate change.
5. **Stronger AppImage compression (#150):** needs a packager passthrough
   for mksquashfs options. zstd-19 with 1 MB blocks: 60.05 MiB, about +90 ms
   cold start. The runtime can't mount xz.
6. **gnustep-packager #39:** the AppImage's GNUstep user Library moves to
   `GNUstep/Library/AppImage/<id>`, so the theme list shows only bundled
   themes; `backends.appimage.gnustepConfig.userLibrary: "host"` keeps the
   old behaviour. Decide when the pin moves past it.
7. **Pandoc and TinyTeX on demand (#150):** pandoc is about 38 MB of the
   AppImage; TinyTeX is now 37 MB on Windows.
8. **OracleTestVMs:** a Windows lease can take the guest agent's 127.0.0.1
   before DHCP and time out on readiness (Linux works around it with a
   wrapper). Fix belongs in OracleTestVMs.
