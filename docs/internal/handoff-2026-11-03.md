  temporary copy. libs-sharing's `GSSharingEmailDraftWithNotice` only gets
  the file URL. markdown-viewer-windows will swap the panel's Email service
  for the app's presenter, on top of #311 (branch `share-panel-email-304`,
  local).
- **#324:** Windows dark mode, display math is a white patch. winuitheme
  thinks it's unlikely to be the theme. Compare with rc2 (alpha12); likely
  `OMMarkdownRendererMath` on a dark background.

  winuitheme suspects carry-0.32.0.5 (hinted metrics off at 125%/150%).
  Compare with carry-0.32.0.4; if it's the backend, file it on
  plugins-themes-winuitheme.
- **#316:** Adwaita alpha19 (207f446) for the Linux packages.
  markdown-viewer-linux.
- **#313:** gnustep-packager v0.1.6. markdown-viewer-linux, with Windows
  for the MSI.
- **#318:** split-view stalls. performance-dashboard owns the libs-gui
  text-cache patch and its upstream path (UPSTREAM_POLICY, Dan's

  Not a regression.
